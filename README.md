# OpenTelemetry instrumentation for `redis`

[![License](https://img.shields.io/badge/license-Apache%202.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![OpenTelemetry Specification](https://img.shields.io/badge/OpenTelemetry-Specification-blueviolet)](https://opentelemetry.io/docs/specs/otel/)

`otel_redis` is an [OpenTelemetry](https://opentelemetry.io/) instrumentation for `redis` that
easily adds standard observability to applications that use `redis`.  This package depends on 
[dartastic_opentelemetry_api](https://pub.dev/packages/dartastic_opentelemetry_api).

This package can be used with any OTel backend because it's compliant with the OpenTelemetry Specification.

This package supports Android, iOS, Linux, macOS and Windows, for versions of `redis` that support those platforms.

This Apache-2.0 package is professionally maintained and supported with 💙 by Michael Bushe,
Dart and Flutter Maintainer at OpenTelemetry and the creator of [dartastic_opentelemetry](https://pub.dev/packages/dartastic_opentelemetry)
and [dartastic_opentelemetry_api](https://pub.dev/packages/dartastic_opentelemetry_api). This package is professionally supported by
[Dartastic.io](https://dartastic.io).

OpenTelemetry instrumentation for package:redis. Wraps Redis commands in CLIENT-kind spans following OTel stable semantic conventions (db.system.name=redis, db.operation.name, server.address).

Span names follow OTel stable semantic conventions:
`{operation.name} {target}` with no system prefix (the system is
already in `db.system.name` / `messaging.system`).

Part of the [Dartastic](https://dartastic.io) OpenTelemetry family.
